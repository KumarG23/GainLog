PRIVATE FITNESS SYSTEM

GainLog

A private, single-user fitness, nutrition, and health-trend application built to turn training data into useful decisions.

Google Health integration

GainLog can connect to Google Health only after the user grants explicit read-only permission. The integration is used to import selected sleep, activity, fitness, and health-metric data into the user's private GainLog service.

Availability

GainLog is not offered as a public consumer service and does not support public account registration.
