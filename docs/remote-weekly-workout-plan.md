# Remote weekly workout plan — rollout contract

GainLog keeps completed workouts as immutable history. The app's built-in five-day template is a fallback skeleton; an API-owned override replaces the scheduled exercises for a day. The client still computes conservative, exact-template/exact-exercise recommendations from completed pre-Monday history and leaves all actual set fields blank. Wednesday remains cardio-only.

- `GET /workout-plan?weekStart=YYYY-MM-DD` (Monday, Eastern week) returns `{weekStart, revision, overrides}`. It reads the newest version effective on or before that week; no row means revision `0` and no overrides.
- `PUT /workout-plan?weekStart=YYYY-MM-DD` accepts `{expectedRevision, overrides}` for the current or next eight weeks. The complete override map is replaced atomically, not merged. Preserve other days from GET when editing one. A stale revision returns `409`; reload and reconcile, never blindly retry. The response is the saved revision and validated plan. An explicit edit to the current week is permitted; future weeks inherit the newest version unless overridden.
- Each overridden lifting day contains the complete ordered list of strength exercises, each with `name`, `sets`, `targetReps`, `rest`, optional `cue`, and exactly two `substitutions`. Names are exact history identities; do not alias machine variants. Recovery cannot contain strength exercises. The optional elliptical finisher and Wednesday easy cardio remain built into the app.
- Timed exercises use `measure: "seconds"` with `targetReps` as the target seconds range (for example `"40–60"`). Legacy exercises omit `measure` and default to reps. Keep timed exercises out of the live override until both the schema-v3 backend and a compatible signed client are deployed and verified: older clients cannot represent seconds and may log them as reps. Completed timed sets store `measure`, `seconds`, zero reps and optional load; never treat timed seconds as rep PRs or volume.
- The app loads workout history and plan together on entry to Log and fails closed when an enabled remote plan request fails. Re-select a draft after an explicit plan edit; an in-progress draft is never silently overwritten. A compatible V2 Android build still needs `EXPO_PUBLIC_GAINLOG_REMOTE_PLAN=1`; later plan-data edits need no APK.

## Top-set progression (2026-11-25, not yet deployed)

- The weekly weight recommendation (`buildWeightRecommendation` in `utils/workoutTemplates.ts`) and the post-workout coach evidence (`_build_prompt` in `backend/main.py`) now accept a second way to qualify at a load: the first prescribed set is at least `TOP_SET_OVERSHOOT_REPS` (3) over the top of the saved range and no prescribed set is below the bottom. The original path (every prescribed set at the top) is unchanged. Reason: sets taken near failure lose 3–4 reps per set, so the all-sets rule never fired even with first sets far above the range.
- The client now requires the **two most recent** sessions of that exercise on that template to qualify at the current load. Previously any two sessions in history counted, so an old good day could earn a step after a recent miss.
- Each past session is judged against the prescription **saved with that log** (`targetRepsMin`, `targetRepsMax`, `prescribedSets`), not today's plan, matching the coach. Editing a range or set count therefore never re-scores old sessions into an increase or a reduction. A log with no saved prescription cannot earn an increase; it can still trigger a reduction against the current plan range.
- A session counts toward an increase only when the number of logged sets equals the saved prescribed count, in the app and the coach alike. Extra sets disqualify it until GainLog can tell warm-ups from working sets. The reduce rule still reads the last prescribed-count sets.
- Effort, pain, note and same-week safety vetoes, the Monday freeze, template isolation, the reduce rule and load-step inference are unchanged. The coach still judges the single current session; the Log screen needs two.
- Needs a backend deploy and a new signed client build before it is live. Ranges stay as prescribed: prefer letting the load step up over widening a range to match logged reps.
- 2026-11-25: week of 2026-11-23 revision 5. Legs: Goblet Squat replaced by 45-Degree Back Extension (second hip hinge); Dumbbell Romanian Deadlift substitutes now Barbell/Smith Machine Romanian Deadlift. Pull, Upper unchanged.
